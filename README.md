1. Project Overview

This project is a Daily Calorie Tracking Console Application created using Python.
It helps users to:

Log their meals

Enter calorie amount for each meal

Calculate total calorie intake

Compute average calories per meal

Compare total calories against a personal daily limit

Display clean, formatted CLI report

(Bonus) Save the session summary to a text file
